## Backend Analytics

Python module:

- `backend/api/metrics.py`

Required Python packages:

- `numpy`
- `pandas`

Install:

```powershell
pip install numpy pandas
```

## Frontend Dashboard

Frontend path:

```powershell
cd frontend
```

Install dependencies:

```powershell
npm install
```

Run locally:

```powershell
npm run dev -- --host 0.0.0.0 --port 5188 --strictPort
```

Build:

```powershell
npm run build
```

Important frontend packages are listed in `frontend/package.json` and locked in `frontend/package-lock.json`.

## Notes

- `node_modules/` is intentionally not included in the zip because it is generated by `npm install`.
- `frontend/dist/` is intentionally not included because it is generated by `npm run build`.
- The dashboard polls `/api/simulate/latest` and posts to `/api/simulate`; until Member 2's API is available, it displays demo data.
